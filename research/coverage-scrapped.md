# Scrapped and rewritten claims (deleted and edited docs, all refs)

Method: in sge, ssg, balticporter, re-scale and lls I ran `git log --all --diff-filter=D --name-only` and read every deleted status, audit, gap or progress doc at `<deleting-commit>^:<path>`. The extracted copies are in `scratchpad/deleted/`. For CLAUDE.md, README.md, PROGRESS.md and `docs/architecture/platform-targets.md` I ran `git log --all --reverse -p` and collected removed (`^-`) lines containing %, N/M, "complete", "ported", "done" or "100%". The raw output is `scratchpad/deleted/removed-lines.txt` (1,050 unique lines, 947 of them from balticporter PROGRESS.md).

re-scale and lls returned nothing relevant: no deleted status docs, and the only removed claim line is a README memory-test sentence.

Hashes are short hashes from the named repo. "Deleted by" names the commit that removed the file or line. The subject of that commit is quoted where it hides the deletion.

## 3. Most talk-worthy items

1. **GlyphLayout across three regimes.** 2026-03-10 audit doc: "All public methods present" (deleted `dd580c6b`). 2026-03-10: the same file sits in the "return removal COMPLETE" batch Q1. 2026-06-10 review: truncation is a no-op because a loop `break` became a method-level `boundary.break`. 2026-07-28 BP: GlyphLayout still has silent `break`-in-switch sites in the deterministic output. Every regime got its control flow wrong.
2. **Audit DB "0 major" in a week.** sge went from 19 majors (03-03) to 0 (03-10, `a6c89321`). The per-package audit docs were deleted on 03-19 in a commit titled "Add sge-dev CLI toolkit". The 04-18 re-audit then found 24 MAJOR files that had been marked `pass`. That report was deleted on 04-20 in a "CI hardening" commit, the same day ~1,200 covenants were stamped.
3. **Denominator games.** liqp "117/117 (100%)" vs 117/138 files and 60–70% behaviour (deleted 04-07 analysis). README "116/116 tests" became "2518 tests" with 1,481 `.fail`-pinned. Baltic Porter's KaTeX denominator drifted 474 → 466 → 496.
4. **ssg knew about body-level break/return loss on 2026-04-07** ("Pattern 1", deleted `acd23f47` under an unrelated subject), two months before the June reviews.
5. **Baltic Porter's own silent-defect table** (deleted `e8538e4f`): 151 `==` sites, 290 dropped `break`s, 156 discarded anonymous-class bodies, and 221 → 0 `@Test`, all compiling green. Even there, two prior residue counts "were quoted with nothing computing them".
6. **Hand ports missing classes, seen from the generator side** (removed `d9283703`): the engine had more types than the hand port in 8 of 9 libraries. jbump's `MathUtils.scala` was really `Extra.java` under a reused name. ssg-mermaid shares only 0–25% of member names with upstream.
7. **Stale claims never removed**: "The core port is complete: 539 of 605" (sge platform-targets.md), "31 types" and "99.7% sass-spec" (ssg README).
